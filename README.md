# Housing Price Prediction using Linear Regression and MLPClassifier

Classify residential housing prices into three categories (low / medium / high) using two scikit-learn models: a regularized **Multiple Linear Regression** and a **Multi-Layer Perceptron Classifier (MLPClassifier)**. Performance is compared using 5-fold cross-validation with balanced accuracy.

## Dataset

- **Source:** [Real-Estate And Housing Price Prediction (Kaggle)](https://www.kaggle.com/datasets/abdullahmeo/housing-price-prediction)
- **Size:** ~30 kB, 545 records
- **Columns:** 13 total — 6 integer (`price`, `area`, `bedrooms`, `bathrooms`, `stories`, `parking`), 6 boolean (`mainroad`, `guestroom`, `basement`, `hotwaterheating`, `airconditioning`, `prefarea`), and 1 string (`furnishingstatus`)
- **Target:** `price` — a continuous numeric value, later discretized into 3 class labels

Place the raw CSV at `data/housing_price_data.csv`.

## Preprocessing

Handled by [preprocess.py](preprocess.py). It produces `data/housing_price_process_data.csv` with the following transformations:

1. **Binary encoding** — the 6 boolean columns are mapped from `yes`/`no` to `1`/`0`.
2. **One-hot encoding** — the `furnishingstatus` column (`furnished`, `semi-furnished`, `unfurnished`) is expanded into three boolean columns.
3. **Target binning** — the continuous `price` is converted into three class labels:
   - **Class 0:** price ≤ 5,000,000
   - **Class 1:** 5,000,000 < price ≤ 10,000,000
   - **Class 2:** price > 10,000,000

Run preprocessing with:

```bash
python preprocess.py
```

## Models

Both models live in their own module and are orchestrated by [main.py](main.py).

### Linear Regression — [models/linear_regression.py](models/linear_regression.py)
- **Model:** `sklearn.linear_model.Ridge` (Multiple Linear Regression with L2 regularization) using default parameters.
- **Classification strategy:** the continuous prediction is bucketed into a class label:
  - prediction `< 0.5` → Class 0
  - `0.5 ≤` prediction `< 1.5` → Class 1
  - prediction `≥ 1.5` → Class 2

### MLPClassifier — [models/mlp_classifier.py](models/mlp_classifier.py)
- **Model:** `sklearn.neural_network.MLPClassifier`, wrapped in a `Pipeline` with `StandardScaler` so features are scaled before entering the network.
- **Architecture:** one hidden layer; number of nodes varied over `{20, 40, 60, 80, 100}`.
- **Learning rates:** `{0.001, 0.01, 0.1}`.
- **Grid:** all 15 (hidden size × learning rate) combinations are evaluated with 5-fold CV; the best config is highlighted in the output table.
- **Classification strategy:** output is already a class label — no conversion needed.

## Experiment

- **Cross-validation:** 5-Fold (≈436 training / 109 testing records per fold).
- **Metric:** **Balanced Accuracy** — chosen because the three price classes are imbalanced, and balanced accuracy averages recall per class so minority-class performance is not drowned out.

## Plots

`main.py` calls three plotting helpers from the [plots/](plots/) folder:

- **[plots/data_plot.py](plots/data_plot.py)** — `plot_class_distribution` shows how many houses fall into each price class with counts and percentages. Called before training to give context on the target distribution.
- **[plots/linear_regression_plot.py](plots/linear_regression_plot.py)** — bar chart of per-fold balanced accuracy with the mean drawn as a horizontal line; the best-performing fold is highlighted in light green.
- **[plots/mlp_classifier_plot.py](plots/mlp_classifier_plot.py)** — grouped bar chart across the full (hidden size × learning rate) grid with error bars for std; the best config is outlined in green.

## Getting started

### Requirements
- Python 3.9+
- Dependencies listed in [requirements.txt](requirements.txt) — `pandas`, `numpy`, `scikit-learn`, `ipykernel`, `rich`, `matplotlib`

```bash
pip install -r requirements.txt
```

### Run

```bash
# 1. Download the raw CSV from Kaggle and save it to data/housing_price_data.csv
# 2. Train and evaluate the models — main.py auto-runs preprocessing if needed
python main.py
```

> `main.py` checks for `data/housing_price_process_data.csv` at startup and only runs preprocessing if the file is missing. To regenerate it manually (e.g. after editing `preprocess.py`), either delete the file or run `python preprocess.py` directly.
